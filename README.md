# 自动账本

个人使用的 Android 自动记账应用安装包与在线更新清单。

## 最新版本

- 版本：v1.4.0（通知栏专用回退版）
- 安装包：`ZiDongZhangBen-v1.4-android.apk`
- 支持：Android 8.0 及以上
- SHA-256：`8B416D7C25485A12F7F5967209BA433AD40CF78E9DA3D041981F47BE86EDC047`

## 自动识别范围

v1.4 已按要求删除付款页面识别和无障碍服务。自动识别仅处理微信、支付宝实际发出的状态栏付款通知；通知没有金额或根本没有通知时不会自动记账。

## 隐私说明

- 本仓库仅包含签名 APK、`version.json` 和公开更新说明。
- 手机中的预算、分类、账目以及付款通知内容不会上传到此仓库。
- App 联网仅用于读取 `version.json` 和下载新版 APK。
- 安装前 App 会核对 APK 的 SHA-256，之后仍需用户在安卓系统界面确认更新。
