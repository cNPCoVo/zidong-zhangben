# 自动账本

个人使用的 Android 自动记账应用安装包与在线更新清单。

## 最新版本

- 版本：v1.2.0
- 安装包：`ZiDongZhangBen-v1.2-android.apk`
- 支持：Android 8.0 及以上
- SHA-256：`D5782EE23C93FB50748CABD43ADA07040D8E3767F1F30A9A783734A5CCCEC253`

## 隐私说明

- 本仓库仅包含签名 APK、`version.json` 和公开更新说明。
- 手机中的预算、分类、账目以及付款通知内容不会上传到此仓库。
- App 联网仅用于读取 `version.json` 和下载新版 APK。
- 安装前 App 会核对 APK 的 SHA-256，之后仍需用户在安卓系统界面确认更新。
