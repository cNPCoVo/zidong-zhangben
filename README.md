# 自动账本

个人使用的 Android 自动记账应用安装包与在线更新清单。

## 最新版本

- 版本：v1.5.0
- 安装包：`ZiDongZhangBen-v1.5-android.apk`
- 支持：Android 8.0 及以上
- SHA-256：`EC2CA140A5235F081189E1BF7E46B7297025D835666491E2DF5CDC76BACEDA8E`

## 本版功能

- 重新加入仅限微信、支付宝的付款页面识别，支持付款、转账、红包的两阶段确认。
- 保留状态栏通知识别作为补充。
- 悬浮分类窗使用短时前台服务，提高新版 Android 上从后台弹出的可靠性。
- 新增 CSV、TXT、ZIP 账单导入、导入预览和交易去重。
- 保留月度总预算、分类预算、超支提醒和在线更新。

## 隐私说明

- 本仓库仅包含签名 APK、`version.json` 和公开更新说明。
- 手机中的预算、分类、账目、账单文件以及识别结果不会上传到此仓库。
- 页面识别服务仅配置给微信和支付宝，并跳过密码输入框。
- App 联网仅用于读取 `version.json` 和下载新版 APK。
- 安装前 App 会核对 APK 的 SHA-256，之后仍需用户在安卓系统界面确认更新。
