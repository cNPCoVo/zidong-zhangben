# 自动账本

个人使用的 Android 自动记账应用安装包与在线更新清单。

## 最新版本

- 版本：v1.3.0
- 安装包：`ZiDongZhangBen-v1.3-android.apk`
- 支持：Android 8.0 及以上
- SHA-256：`801F908D3E1E3FCCB946397FC235C3CBE36E799F8E44E0E66F9C22EF8F94D14E`

## 微信无通知识别

v1.3 增加可选的“付款页面识别”。微信不发状态栏通知时，可在 App 首页进入安卓无障碍设置，开启“自动账本付款页面识别”。该服务只接收微信和支付宝的前台页面文字，并且只在出现支付完成字样和金额时创建待分类付款。

## 隐私说明

- 本仓库仅包含签名 APK、`version.json` 和公开更新说明。
- 手机中的预算、分类、账目以及付款通知内容不会上传到此仓库。
- App 联网仅用于读取 `version.json` 和下载新版 APK。
- 付款页面识别结果只在手机本地处理，不上传页面内容或账目。
- 安装前 App 会核对 APK 的 SHA-256，之后仍需用户在安卓系统界面确认更新。
